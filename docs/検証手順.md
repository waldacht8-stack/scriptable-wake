# 実機での検証手順（要件書 10.2）

アプリを本格的に使う前に、iPhone で次のことを確かめてください。結果を教えてもらえれば、それに合わせて作り直します。
所要時間は全部で30分ほどです（「翌朝まで待つ」項目を除く）。

結果は各項目の「□」に ✓ か ✗ を付けて、気づいたことをメモしてください。

---

## 検証1：アラームをラベル名でオン/オフできるか（最重要）

アプリ全体がこれを前提にしています。

1. 時計アプリ →「アラーム」→ 右上「＋」
2. 時刻を「今から3分後」にする。「ラベル」を **起床-テスト** にする。「繰り返し」は「しない」、「スヌーズ」はオフ →「保存」
3. ショートカットアプリ →「ショートカット」タブ → 右上「＋」
4. 「アクションを検索」で **アラーム** と入力し、**「アラームを切り替え」**（似た名前なら「アラームをオン/オフ」など）を追加
5. アクションの中の青い文字をタップして、
   - 「オフにする」を選ぶ
   - アラームは一覧から **起床-テスト** を選ぶ
6. 下の ▶（実行）をタップ → 時計アプリでアラームがオフになったか確認
7. 「オフ」を「オン」に変えてもう一度 ▶ → オンに戻るか確認

- ✓ アラームをオン/オフするアクションがある（2026-10-07 利用者が確認）
- □ ラベル名（起床-テスト）のアラームを選べた
- □ オフにできた
- □ オンにできた
- メモ：アクションの正確な名前と、選べる項目（「オン」「オフ」「切り替え」など）：

## 検証2：鳴り終わった1回限りのアラームを、次の日にもう一度使えるか

1. 検証1のアラームを鳴らして止める（止めると、1回限りのアラームは自動でオフになります）
2. 検証1のショートカットで「オン」にする
3. 時計アプリで、そのアラームが「明日の同じ時刻」になっているか確認（翌日、実際に鳴るか）

- □ 鳴った後にショートカットでオンにできた
- □ 翌日の同じ時刻に鳴った

## 検証3：ショートカットでアラームの時刻を変えたり、削除したりできるか

1. ショートカットのアクション検索で **アラーム** と入力し、出てくるアクションを全部メモする
   （例：「アラームを作成」「アラームを切り替え」「すべてのアラームを取得」「アラームを編集」「アラームを削除」など）
2. 「時刻を変える」「削除する」アクションがあれば、起床-テストで試す

- □ 時刻を変えられる（できれば「段階の自動調整」が復活できます）
- □ 削除できる

## 検証4：時刻のオートメーションがロック中・低電力モードでも動くか

1. ショートカットアプリ →「オートメーション」タブ → 右上「＋」→「特定の時刻」
2. 時刻を「今から5分後」、「毎日」→「すぐに実行」を選ぶ →「次へ」
3. 「新規の空のショートカット」→「通知を表示」アクションを追加し、本文を「オートメーションのテスト」にする
4. iPhone をロックして待つ。もう一度、低電力モード（コントロールセンターの電池のボタン）をオンにして試す
5. 終わったらこのオートメーションは削除してOK

- □ ロック中に通知が届いた
- □ 低電力モード中も届いた

## 検証6：ロック画面ウィジェットの更新とタイマー表示

先に「セットアップ手順書」の「1. スクリプトを入れる」を済ませてください。

1. ロック画面を長押し →「カスタマイズ」→「ロック画面」→ 時計の下の枠をタップ
2. 「Scriptable」→ **長方形** のウィジェットを追加 → 追加したウィジェットをタップ
3. 「Script」で **起床ウィジェット** を選ぶ。「Parameter」に **todo** と入力
4. ロック画面に戻り、Todo が表示されるか確認
5. 「Parameter」を **night** に変えて、「就寝まで」の数字が1秒ごとに減っていくか確認
6. 円形・1行（時計の上の枠）も同じように追加して確認
7. 半日ほど置いて、表示が時間帯に合わせて切り替わっているか確認（Parameter は空にする）

- □ todo：Todo が表示された（既存 Todo アプリのウィジェットでは出なかったもの）
- □ night：タイマーがロック画面で動き続けた
- □ 円形・1行も表示された
- □ 時間帯の切り替わり（遅れは15〜30分程度まで許容）
- メモ：表示が崩れている箇所（スクリーンショットがあると助かります）：

アプリ内でも見た目を確認できます：Scriptable で「起床ウィジェット」をタップ → 種類を選ぶ。

## 検証7：既存 Todo アプリのデータと、ロック画面に出ない原因

**データの場所と形式は、パソコン側で確認済みです。**

- 場所：Scriptable フォルダの `todo-data/todo-data.json`
- 形式：`version: 2`。`todos` の中に `title`（名前）・`done`（完了したか）・`due`（期限）・`allDay`（終日か）など
- 本アプリはこのファイルを **読むだけ** で、書き換えません

**ロック画面に出ない原因（有力な候補）**

既存 Todo アプリのウィジェットは、表示する前に毎回「カレンダーとの同期」と「通知の予約し直し」をしています（それぞれ最大10秒待つ）。
iPhone のウィジェットは、使える時間とメモリがとても少ないため、この処理の途中で打ち切られて何も表示されていない可能性が高いです。

本アプリのウィジェットは、**ファイルを読んで描くだけ** にしてあります（カレンダー・通知・通信に触らない）。
検証6で「Parameter に todo」を入れて Todo が表示されれば、この説が正しいことになり、F-06（Todo のロック画面表示）はこのウィジェットで満たせます。

- □ 起床ウィジェット（todo）では Todo が出た
- □ 既存の TODO ウィジェットは、やはり出なかった
