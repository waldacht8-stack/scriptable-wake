# セットアップ手順書（段階式目覚まし）

この順番で進めてください。ボタン名は iPhone の画面の表記です（iOS のバージョンで少し違うことがあります。違っていたら教えてください）。

> 先に「検証手順.md」の **検証1** だけは済ませてください。ショートカットでアラームをオン/オフできることが、この手順の前提です。

---

## 1. スクリプトを入れる

1. パソコンの VS Code で、ターミナルに `.\tools\deploy.ps1` と入力して Enter
2. 数分待つと、iPhone の Scriptable に **起床** と **起床ウィジェット** が出てきます
3. Scriptable で **起床** をタップして一度開く
   - 「通知を許可しますか」と聞かれたら「許可」
   - これで設定ファイル（`WakeApp/config.json`）が作られます
4. 下の「⚙️ 設定」で、段階の時刻・曜日・出発時刻・就寝時刻を自分に合わせる

| 最初の設定 | 内容 |
| --- | --- |
| 段階 | 6:50 そっと／7:00 ふつう／7:03 しっかり／7:06 最終 |
| 起床する曜日 | 月〜金（出発 7:45）。土日は起床しない |
| 就寝 | 23:30（23:00 にリマインド） |
| 祝日 | アラームなし（カレンダー「日本の祝日」で判定） |

## 2. 時計アプリにアラームを作る

段階の数だけ（最初は4つ）作ります。時刻は設定画面と **同じ** にしてください。

1. 時計アプリ →「アラーム」→ 右上「＋」
2. 時刻：6:50、繰り返し：**しない**、ラベル：**起床-段階0**、サウンド：静かな音、スヌーズ：**オフ** →「保存」
3. 同じように作る

| ラベル | 時刻 | サウンド |
| --- | --- | --- |
| 起床-段階0 | 6:50 | 静かな音 |
| 起床-段階1 | 7:00 | 普通の音 |
| 起床-段階2 | 7:03 | 大きく速い音 |
| 起床-段階3 | 7:06 | 一番強い音 |

4. 作ったら、4つともオフにしておく（毎晩ショートカットがオンにします）

時刻を変えたくなったら、時計アプリと設定画面の **両方** を直してください（ショートカットからは時刻を変えられないため）。

---

## 3. ショートカットを作る（必要なのは2つだけ）

ショートカットを使うのは、**Scriptable ではどうしてもできないこと** だけにしました。

| ショートカットが必要なこと | 理由 |
| --- | --- |
| 時計アプリのアラームをオン/オフする | Scriptable には時計アプリを操作する機能がない |
| バーコードを読み取る | Scriptable にはカメラでバーコードを読む機能がない |

それ以外（正午の未チェックイン判定、週の振り返り、明日だけオフ、就寝リマインド、持ち物の通知）は、Scriptable だけで動きます。

ショートカットアプリ →「ショートカット」タブ → 右上「＋」で新しく作り、上の名前の部分をタップして名前を付けます。
**名前は下の表記どおりに** してください（通知やアプリから名前で呼び出します）。

Scriptable のアクションは、アクション検索で **Scriptable** と入れると出る **Run Script（スクリプトを実行）** を使います。

- 「Script」：**起床** を選ぶ
- 「Parameter」：下の手順で指定する文字
- 「Run In App」：**オフ**（アプリを開かずに裏で動かす）

Run Script の結果は、次のアクションで「Run Script」（青い丸の付いた変数）として選べます。

### S-01「アラーム準備」（必須）

明日が起床日かを Scriptable に聞き、起床日ならアラームをオン、そうでなければオフにします。
「明日だけオフ」にしたときも、アプリがこのショートカットを呼んでアラームをオフにします（専用のショートカットは不要です）。

1. **Run Script**：Script＝起床、Parameter＝`plan`
2. **if文**：入力＝「Run Script」、条件＝「が次と等しい」、テキスト＝`ON`
3. if の中（「もし」と「その他の場合」の間）に **アラームを切り替え** を4つ置き、それぞれ「オン」・起床-段階0〜3 を選ぶ
4. 「その他の場合」の中に **アラームを切り替え** を4つ置き、それぞれ「オフ」・起床-段階0〜3 を選ぶ

結果は通知でも届きます（「⏰ アラームをオンにしました」など）。

### S-02「起床チェックイン」（必須）

洗面所のバーコードを読むと、残りのアラームをオフにして記録します。

1. **QR/バーコードをスキャン**
2. **テキスト**：`checkin:` と入力し、続けて「QR/バーコード」の変数を入れる（例：`checkin:` の後ろに青い丸）
3. **Run Script**：Script＝起床、Parameter＝上の「テキスト」
4. **if文**：入力＝「Run Script」、条件＝「が次と等しい」、テキスト＝`OK`
5. if の中に **アラームを切り替え** を4つ（「オフ」・起床-段階0〜3）と、**結果を表示**「おはようございます。アラームをオフにしました」
6. 「その他の場合」の中に **結果を表示**「チェックインできませんでした。アラームはそのままです」

**最初の1回目はコードの登録になります。** 歯磨き粉などのバーコードを読むと「✅ コードを登録しました」と通知が出ます（アラームはオフになりません）。登録をやり直すときは、起床アプリの「設定」→「バーコード」→「登録を消す」。

チェックインできる時間は **起床日の段階0の2時間前〜正午** だけです。夜の歯磨きでうっかり読んでも、翌朝のアラームは消えません。

### あると便利なもの（なくても動きます）

- **「次の起床は」**（Siri 用）：Run Script（Parameter＝`next`）→ **テキストを読み上げる**「Run Script」。「Hey Siri、次の起床は」で答えます
- **「テストで鳴らす」**：**現在の日付** → **日付を調整**（1 分を追加）→ **アラームを作成**（時刻＝調整された日付、ラベル＝`起床-テスト`）。鳴ったら時計アプリで削除

### 明日だけオフ

起床アプリのホーム画面 →「💤 明日だけオフ」。アラームがもうオンなら、そのまま「アラーム準備」が呼ばれてオフになります。
取り消しは同じ場所の「↩︎ お休みを取り消す」→「開く」でアラーム準備を実行。

## 4. オートメーションを作る（必要なのは1つだけ）

ショートカットアプリ →「オートメーション」タブ → 右上「＋」→「特定の時刻」→ **毎日 20:00** →「すぐに実行」（「実行前に確認」だと止まります）→ **ショートカットを実行**：アラーム準備

- 時刻は、就寝時刻より前なら変えて構いません
- これが動かなかった日のために、**就寝リマインドの通知をタップしても「アラーム準備」を実行できます**（通知に「アラーム準備がまだです」と出ます）
- 以前の版にあった「正午の判定（noon）」「週の振り返り（weekly）」のオートメーションは **不要** になりました。作ってしまった場合は削除して構いません

### A-04 NFC タグ（余裕があれば）

NFC タグ（数百円）を洗面所に貼る場合：「＋」→「NFC」→ タグを読み取って名前を付ける →「すぐに実行」→

1. **Run Script**：Script＝起床、Parameter＝`nfc`
2. 以降は S-02 の手順4〜6と同じ


### Apple Watch の電池（追加要件）

調べた結果、**Scriptable でもショートカットでも Apple Watch の電池残量は取れません**（Scriptable が読めるのは iPhone の電池だけで、ショートカットにも Watch の残量を取るアクションがありません）。
代わりに、Apple Watch に標準で付いている **充電リマインダー** を使います。電池が少ないと、就寝前に Watch に「充電してください」と通知が来ます。

1. iPhone の **ヘルスケア** アプリ →「ブラウズ」→「睡眠」→「スケジュール」で、睡眠スケジュール（就寝 23:30 など）を設定する
2. iPhone の **Watch** アプリ →「マイウォッチ」→「睡眠」→ **充電リマインダー** をオン

- 就寝準備の時刻の前に、電池がおよそ **30%未満** なら充電を促す通知が来ます（30% は Apple の決まりで、変えられません）
- 満充電になったときも通知されます
- 起床アプリの就寝リマインドにも「iPhone と Apple Watch の充電を忘れずに」と毎晩出ます

睡眠スケジュールの就寝時刻は、起床アプリの設定の就寝時刻と合わせておくと分かりやすいです。
（睡眠スケジュールにも起床アラームがありますが、段階アラームと重なるので、スケジュールのアラームは **オフ** にしてください）

## 5. ロック画面にウィジェットを置く

1. ロック画面を長押し →「カスタマイズ」→「ロック画面」
2. 時計の下の枠 →「Scriptable」→ **長方形** と **円形** を追加
3. 時計の上の枠（日付の横）→「Scriptable」→ **1行** を追加
4. 追加したウィジェットをそれぞれタップ →「Script」で **起床ウィジェット** を選ぶ（Parameter は空のまま）

時間帯で表示が変わります。

| | 起床中 | 朝 | 昼間 | 夜 | 就寝前 |
| --- | --- | --- | --- | --- | --- |
| 1行 | ⏰ チェックインして | 🚪 7:45 出発 | ✅ Todo 残り3件 | 🌙 23:30 就寝 | ⏰ 明日 7:00 起床 |
| 長方形 | 今の段階・次の段階 | 出発までのタイマー・次のルーティン・遅れ | Todo 上位3件 | 就寝までのタイマー・明日の起床と予定 | 明日の起床・段階数・今寝た場合の睡眠時間 |
| 円形 | 段階の番号 | 出発までの輪 | 今朝の点数 | Todo の件数 | 今週の平均点 |

- Parameter に `todo` と入れると、いつでも Todo の表示に固定できます（ほかに `night` `presleep` なども可）
- タップすると：朝はルーティンを1つ「完了」にして画面を開く／昼間は TODO アプリを開く／それ以外は起床アプリを開く
- 1行の「出発」「就寝」は、残り時間ではなく時刻を出しています（1行の枠でタイマーが動くか分からないため。検証後に変えられます）

## 毎日の流れ

1. 20:00 に自動でアラーム準備（通知が届く）
2. 就寝30分前に「🌙 あと30分で就寝」の通知（充電も）
3. 朝、段階0〜3が順に鳴る。止めても次の段階は残る
4. 洗面所でショートカット「起床チェックイン」→ バーコードを読む → 残りのアラームがオフ、記録される
5. ロック画面に出発までのタイマー。ウィジェットをタップしてルーティンを進める
6. 出発5分前に「🎒 持ち物チェック」の通知
7. 昼は Todo、夜は就寝までの時間を表示

## 困ったとき

- 起床アプリ →「🔧 動作確認」で、今の時間帯・アラーム準備の判断・Todo が読めているか・予約中の通知の数が見られます
- データは iCloud Drive の `Scriptable/WakeApp/` にあります（config.json＝設定、state.json＝今日の状態、sessions.json＝起床の記録）
- 何かが失敗したときは、**アラームが鳴る側** に倒れるように作ってあります（準備でエラー → 曜日の設定だけで判断してオンにする、チェックインでエラー → オフにしない）
